# AI Spend Audit Tool

A full-stack Spring Boot application built for **Credex** to help users find hidden savings in their AI subscription stacks.

## Project Links
- **Live Demo:** [https://ai-spend-audit-xz7r.onrender.com](https://ai-spend-audit-xz7r.onrender.com)
- **Video Walkthrough:** [Loom Video](https://www.loom.com/share/296f375ce069469cb814591e532994c8)

## Key Features
- **Smart Logic:** Identifies high-cost tiers (like Cursor Business) and suggests Pro plan downgrades.
- **AI Strategy:** Generates personalized optimization summaries for every audit.
- **Lead Capture:** Automatically stores audit data as high-intent sales leads.

## Tech Stack
- **Backend:** Java 17, Spring Boot 3.x
- **Frontend:** HTML5, Tailwind CSS, JavaScript (AJAX)
- **Deployment:** Docker, Render (Cloud)

# User Interviews Summary

### Interview 1: Engineering Senior
- **Insight:** Uses multiple free tools (ChatGPT, Claude) to avoid $20/mo cost.
- **Problem:** Finds it hard to track which tool is best for which task.

### Interview 2: Freelance Dev
- **Insight:** Paid for Perplexity but cancelled because they didn't use it enough.
- **Problem:** Forget to cancel subscriptions.

### Conclusion
There is a high demand for a "Single View" of AI spend to help users decide which ONE tool is worth the Pro subscription.
